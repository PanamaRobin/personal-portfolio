# Downloadable files

The Files section and the diploma lightbox link to PDFs in this directory by
the paths in `src/data/portfolio.ts`. They are placeholders until the real
documents are dropped in:

- `jorge-herrera-cv-en.pdf`
- `jorge-herrera-cv-es.pdf`
- `bsc-diploma.pdf`
- `aws-saa-certificate.pdf`
- `java-se-certification.pdf`
- `references-letter.pdf`

The diploma lightbox resolves its file from the `diploma` field on each entry
in `initialStudies`, so a filename there must match a file here.
